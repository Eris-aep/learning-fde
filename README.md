# FDE 学习仓库（Python → Web → AI）

按**领域**分文件夹，不按阶段编号。每个领域内部保持同一形状：`dayXX/` + `reading/` + `README.md`。

## 目录规划

| 文件夹 | 对应阶段 | 状态 | 内容 |
|---|---|---|---|
| `python/` | 阶段 1 | 已完成（Day 2–32） | 语法、循环、函数、文件读写、异常处理、模块、命令行工具 |
| `web/` | 阶段 2 | 进行中（2026-11 起，7 周） | HTML/CSS、HTTP、路由、数据库、部署 |
| `ai/` | 阶段 3 | 未开始（阶段开始时创建） | LLM 调用、RAG、Agent 工作流 |
| `deploy/` | 阶段 4 | 未开始（阶段开始时创建） | 上线、运维、交付文档 |
| `projects/` | 跨阶段 | 未开始 | 作品集：从 day 目录抽出的独立项目 |
| `notes/` | 跨阶段（可选） | 未开始 | 笔记、复盘、面试题 |

**四条规则**

1. **一个领域一个文件夹，不用 `stage1/`、`stage2/` 这种编号**：阶段的内容和长度会调整（阶段 2、3 的周数就改过），编号一改就要全仓库重命名。
2. **不预建空文件夹**：git 不跟踪空目录，等阶段真正开始再建，建时放一个 `README.md` 说明用途。
3. **作品从 day 目录抽出**到 `projects/`，day 目录里留一行指向新位置；求职时只发 `projects/` 的链接。
4. 命名统一小写 ASCII、无空格无中文，避免脚本和 CI 里的路径问题。

## 阶段作品：批量文件工具

一个命令搞定「批量加日期前缀」和「按扩展名归档」：

```
cd python/day30
python wenjian_tool.py                              # 不带参数，显示用法
python wenjian_tool.py rename 目标目录              # 加日期前缀
python wenjian_tool.py fenlei 目标目录              # 按扩展名分类
```

安全设计：

- 先预览、输 `y` 才执行，可随时取消
- 可重复运行（幂等），不会叠加第二层前缀
- 目录不存在时给中文提示，不抛 Traceback
- 单个文件失败只跳过它，不中断整批

详细用法与示例输出见 [python/day30/README.md](python/day30/README.md)。
